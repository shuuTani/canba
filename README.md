# canba

ブラウザで動く、Canva 風のかんたんデザインツールです。`index.html` をブラウザで開くだけで使えます。

## デザインツール（index.html）

- テンプレート 4 種（秋の新メニュー / セール告知 / ハッカソン招待 / 白紙）
- 文字の追加（見出し・小見出し・本文、フォント 6 種）、ダブルクリックで書き換え
- 図形（四角・角丸・丸・三角・星・線）
- 選択・ドラッグ移動・四隅で拡大縮小・つまみで回転、中央へのスナップ
- 色・文字サイズ・太字・揃え・透明度・角丸、前面へ／背面へ、複製、削除
- 背景色の変更
- サイズ切り替え（Instagram 投稿 / ストーリー / プレゼン / A4 チラシ）
- 元に戻す・やり直す、PNG 画像として書き出し
- 作業内容はブラウザに自動保存

ショートカット: `Delete` 削除, `Ctrl+D` 複製, `Ctrl+Z` 元に戻す, `Ctrl+Shift+Z` やり直す, 矢印キーで 1px 移動（Shift で 10px）, `Enter` 文字の編集, `Esc` 選択解除

## お絵かき帳（draw.html）

ペン・消しゴム・直線・四角・丸で自由に描けるシンプルなお絵かきページです。
